# Как добавлять цветы в FlowerLover

Все данные находятся в `data/flowers.ts`, а фотографии — в `public/images/flowers`.

## 1. Подготовьте фотографию

- Вертикальная ориентация, желательно `4:5`.
- Рекомендуемый размер: `1200×1500 px`.
- Подходящие форматы: `.webp`, `.jpg`, `.jpeg`, `.png`.
- Цветок лучше располагать около центра: карточка использует `object-fit: cover` и может обрезать края.
- Имя файла пишите латиницей, в нижнем регистре, без пробелов: `hydrangea.webp`.

Скопируйте файл сюда:

```text
public/images/flowers/hydrangea.webp
```

## 2. Добавьте запись

Откройте `data/flowers.ts` и вставьте новый объект внутрь массива `flowers`:

```ts
{
  id: "hydrangea",
  name: "Гортензия",
  latinName: "Hydrangea",
  description:
    "Воздушные соцветия с мягкими переходами оттенков. Символ искренности и тёплых чувств",
  role: "primary",
  seasonality: "summer",
  image: "/images/flowers/hydrangea.webp",
  imageAlt: "Пышная голубая гортензия крупным планом",
  // Заполните, если лицензия фотографии требует указать автора:
  // photoAuthor: "Имя фотографа",
  // photoSourceUrl: "https://example.com/photo",
},
```

Запятая после объекта обязательна. Положение записи в массиве определяет положение карточки в опросе и на странице результатов.

## 3. Важные правила

- `id` должен быть уникальным и стабильным. После публикации не меняйте его: ответы сохраняются именно по `id`.
- Путь `image` начинается с `/images/flowers/` и должен точно совпадать с именем файла, включая расширение.
- Для общих карточек используйте название рода: `Rosa`, `Tulipa`, `Paeonia`.
- `imageAlt` описывает то, что видно на фотографии, а не повторяет только название цветка.
- Описание лучше ограничить одним-двумя короткими предложениями.
- В `role` укажите основную роль цветка: `primary`, `companion`, `filler` или `accent`.
- В `seasonality` укажите основную сезонность: `year-round`, `spring`, `summer`, `autumn` или `winter`.
- Названия и описания ролей и сезонностей находятся в `data/flower-taxonomy.ts`.

Пока фотография не готова, поля `image` и `imageAlt` можно не добавлять — интерфейс покажет серую заглушку.

## 4. Проверьте результат

Если сервер ещё не работает:

```bash
npm run dev
```

Откройте `http://localhost:3000`. После изменения массива страница обновится автоматически.

Перед завершением работы проверьте production-сборку:

```bash
npm run build
```

Если вы уже проходили опрос, нажмите «Пройти заново». При добавлении нового цветка приложение также обнаружит его как ещё не оценённый.
